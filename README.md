# Sistem-Monitoring-IoT-
Sistem ini merupakan aplikasi dan perangkat IoT yang membantu memantau serta  mengendalikan kondisi ruangan untuk menghemat penggunaan energi. Sistem  membaca suhu, kelembapan, dan keberadaan orang di dalam ruangan secara otomatis.  Berdasarkan kondisi tersebut, sistem dapat mengatur perangkat seperti kipas atau  lampu secara otomati.
